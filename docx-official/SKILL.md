# DOCX公文格式转换技能（无红头）

## 功能

将Word文档转换为符合公文格式规范的文档（无红头文件），支持：
- 智能识别文档结构（标题级别、正文、表格）
- 处理从网上复制的文档（去除多余空格、处理非自然回车）
- 识别序号格式（一、(一)、1.、(1)等）
- 表格处理（表头加粗、行间距、对齐方式）

## 公文格式要求

| 项目 | 格式 |
|------|------|
| 纸张 | A4 |
| 页边距 | 上3.7cm、下3.5cm、左2.8cm、右2.6cm |
| 页眉页脚 | 1.5cm、2.8cm |
| 标题 | 方正小标宋简体 二号，居中，行距30磅 |
| 正文 | 仿宋_GB2312 三号，首行缩进2字符，行距28磅 |
| 一级标题 | 黑体 三号不加粗 |
| 二级标题 | 楷体_GB2312 三号不加粗 |
| 三级标题 | 仿宋_GB2312 三号加粗 |
| 四级标题 | 仿宋_GB2312 三号不加粗 |
| 表格标题 | 黑体小四号，居中，加粗 |
| 表头行 | 黑体五号，居中，加粗 |
| 表格正文 | 宋体五号，居中 |
| 页码 | 手动添加（视图→页眉页脚） |

## 使用方法

### 命令行

```bash
python convert_official.py <输入文件.docx> [输出文件.docx] [--no-api]
```

### 参数说明

- 输入文件：必填，原始docx文件
- 输出文件：可选，默认在原文件目录生成`xxx_公文格式.docx`
- `--no-api`：可选，不调用API进行智能分析

### 环境变量

```bash
# Windows
set DEEPSEEK_API_KEY=your-api-key

# Linux/Mac
export DEEPSEEK_API_KEY=your-api-key
```

有API时自动分析文档结构，智能识别标题级别。

## 示例

```bash
# 转换文档
python convert_official.py 班主任日常量化方案.docx

# 指定输出文件
python convert_official.py input.docx output.docx

# 不使用API（纯规则判断）
python convert_official.py input.docx output.docx --no-api
```

## 处理功能

### 文本清洗
- 去除多余空格（保留单个空格）
- 去除中文之间的空格
- 处理特殊空白字符（全角空格、不间断空格、制表符）
- 处理非自然回车（合并被错误分割的段落）

### 序号识别
- 一级标题：一、二、三、...（中文数字+顿号）
- 二级标题：（一）（二）（三）...（中文数字+括号）
- 三级标题：1. 2. 3. ...（阿拉伯数字+点）
- 四级标题：（1）（2）（3）...（阿拉伯数字+括号）

### 表格处理
- 自动识别表格位置
- 表头行加粗、居中
- 设置表格行距（20磅）
- 统一单元格对齐方式

## 注意事项

- 确保系统安装有相应字体（楷体_GB2312、仿宋_GB2312、方正小标宋等）
- 页码需要在Word中手动添加
- 转换前建议备份原文件
- 不支持PDF格式，需先转换为docx
